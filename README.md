# Supply — 消耗品 購入リスト

過去の購入日・場所・金額を記録できる、家計簿機能つきの消耗品購入リストです。
`index.html` は Claude の Artifact としてそのまま公開できる単一ファイルです（ビルド不要）。
- Artifact として公開（`capabilities: {db: {}, downloads: true}`）: データは Claude 側の `db` に保存され、端末をまたいで残ります。
- ブラウザで直接開いた場合や未サインイン時: ブラウザの localStorage に保存します。

## 機能
- **購入リスト**: 品名／単価／数量／カテゴリ／購入場所／購入サイクル／前回購入日・経過日数・価格・場所／最安値・その場所・その日
  - カテゴリ別・購入場所別のグループ表示、列見出しクリックまたはプルダウンで並べ替え
  - 購入サイクル（日・週・月・年、「2週間に1回」など）の期日が来た品目は自動でリストに載る
  - 「購入」で日付・場所・単価・数量を記録（最安値との比較を表示）。「外す」で今回はスキップ
- **品目・履歴**: 品目の追加・編集・削除、購入履歴の確認・追加（過去分の入力）・削除
- **集計**: 日／週／月／年ごとのカテゴリ別購入価格の円グラフと、品名別の購入状況リスト
- データの書き出し／読み込み（JSON）、サンプルデータ投入
